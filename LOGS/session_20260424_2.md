## Design decisions made this session

1. **Harness is framework-light, uses plain `transformers`, not
   vLLM/FlashInfer.** The motivation study measures an offline
   quantity. Paging, kernel perf, production constraints are
   irrelevant; we need a clean controlled measurement.
2. **δ depends on Q and K only; V is not quantized on the δ path.**
   δ = KL on attention weight distributions; V doesn't enter the
   weight computation. Quantizing V would fail for short sequences
   (group_size=32 > short-sequence token count) without affecting
   the measurement. V-quantization error propagation through the
   stack is captured by end-to-end accuracy benchmarks later.
3. **Constant-group quantization** (span = 0) is handled by
   folding the constant into the scale so round-trip is exact.
   The standard formula collapses constant groups to zero. Unit
   test `test_constant_group_quantizes_losslessly` guards against
   regression.
4. **Hook architecture: projection hooks + forward wrapper.**
   Capture post-projection Q/K/V via `register_forward_hook` on
   the `q_proj`/`k_proj`/`v_proj` children, then wrap the
   attention module's `forward` to drain the captured tensors
   into an `AttentionTrace`. Works with transformers 4.57's
   Llama-family models. Non-Llama architectures (GPT-2's fused
   `c_attn`, others) are not supported — documented in
   ``run.py``.
5. **`ACCURACY_WORKLOADS = {ruler_32k, gsm8k_cot, humaneval}`.**
   Only these produce a clean per-request scalar in [0, 1], so
   only these contribute to Spearman ρ. ShareGPT and summarization
   contribute to the violin plot and layer heatmap.
6. **RULER-32K is procedural, not a dataset download.** Keeps the
   harness disk-light and seedable. Filler text is ~32 K
   whitespace tokens; real token count depends on the tokenizer.
7. **HumanEval scoring returns NaN** because safe-execution
   sandboxing is out of scope for this harness; the aggregator
   filters NaN. The caller can plug in a sandbox
   (Docker / `exec` via subprocess) to enable real pass@1.
8. **Spearman ρ implemented locally.** Rank-average ties, no SciPy
   dep. Verified ρ = +1 / -1 on monotone synthetic series.
9. **Upstream pins: Triton 3.5.0, PyTorch 2.9.0+cu128,
   transformers 4.57.3, datasets 4.5.0.** vLLM and FlashInfer
   stay TBD until first use (session 3+).

## Bugs found and fixed

1. **Constant-group collapse.** The naive asymmetric formula
   produces `scale = span/levels = 0` when a group is constant,
   collapsing the round-trip to zero. Fixed by folding the
   constant into the scale when `span == 0`. Surfaced by
   `test_constant_group_quantizes_losslessly`.
2. **V-quantization on short axis.** `simulate_quantization(V,
   group_axis=-2)` failed for short sequences because the token
   axis was shorter than `group_size=32`. Removed V quantization
   from the δ path entirely — δ doesn't need it (see decision 2).
3. **Hook attribute mismatch.** transformers 4.57 moved
   `num_attention_heads` and `head_dim` off the attention module
   and onto `attn_module.config`. The hook gated on direct
   attributes and silently returned 0 hooks. Fixed by reading
   from `attn_module.config` when the direct attribute is absent.
4. **Test tolerance for float32 KL noise.** The clamp-then-log path
   leaves ~1e-8 of noise in KL near zero. Loosened the
   non-negativity assertion to `>= -1e-6` and noted the reason in
   the test.

## Addendum (same-session, later): variance-aware three-outcome gate

Accepted a critic's refinement to the pivot criteria. Original rule
was binary — ρ ≥ 0.5 → pass, else pivot. The refinement names a
third outcome: if δ is predictive on reasoning workloads (RULER,
GSM8K) and undetermined on HumanEval, that's a **positive**
finding, not a pivot. KV compression is known to hurt long-range
reasoning more than short-prompt code generation; δ tracking the
former and being silent on the latter is the pattern the research
community would expect and want to see.

**My refinement on top of the critic:** ceiling/floor-effect guard.
"Selective predictiveness" only makes sense if the silent workload
actually has low accuracy variance. Otherwise (variance present,
|ρ| < 0.5) it's a genuine failure of δ on a workload where it
should matter. The gate now reports accuracy stdev alongside ρ and
uses a threshold of 0.10 on the [0,1] accuracy scale.

**Also discovered during test writing:** the gate should compare
`|ρ|` against the threshold, not signed ρ. Higher δ should predict
*lower* accuracy, so the desired signal is ρ near −1, not +1.
Threshold is now `abs(rho) >= RHO_THRESHOLD`. REPORT.md § Motivation
Study Gate now spells this out.
